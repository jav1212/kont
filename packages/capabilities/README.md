# Capacidades transversales

Esta carpeta clasifica capacidades funcionales que sirven a varios dominios sin pertenecer al lenguaje central de una operación empresarial. No es un paquete ni un módulo genérico compartido.

Actualmente contiene autenticación, control de acceso, acceso delegado, organizaciones y perfil. Cada capacidad conserva una responsabilidad y una API pública independientes.
